# Support

Welcome to SupMiner Hardware Checker! We're here to help.

## Getting Help

- **Documentation** — Check the [README](README.md) and docs for usage instructions.
- **Issues** — Search [existing issues](https://github.com/weinotes/supminer-hardware-checker/issues) or open a new one if your problem is not covered.
- **Discussions** — Use GitHub Discussions for questions, ideas, and community conversation.

## How to Report a Problem

1. Search the issue tracker to see if the problem has been reported already.
2. If not, open a [bug report](https://github.com/weinotes/supminer-hardware-checker/issues/new?template=bug_report.md) with:
   - Your hardware and OS details
   - Steps to reproduce
   - Expected vs actual behavior
   - Any error output or logs

## Feature Requests

Have an idea? Open a [feature request](https://github.com/weinotes/supminer-hardware-checker/issues/new?template=feature_request.md). We'd love to hear from you!

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on how to contribute code, report bugs, and suggest improvements.
